# 💰 Money Defense — 돈타워 디펜스 (초기 버전)

워크래프트3 유즈맵 **돈타워(어나더) 초기 버전**을 옮긴 타워 디펜스입니다. 라운드는 끝없이 이어집니다.
원작의 규칙 위에 콘텐츠를 약 4배로 늘렸습니다(난이도·몹 특성·보스·옵션 타워·영웅·연구·아이템·소모품·퀘스트).
`index.html` 한 파일이라 더블클릭하면 브라우저에서 바로 실행됩니다.

**바로 플레이**: https://chs034792-prog.github.io/Money-Defense/

참고 영상: [돈을 버는 건물을 지어 돈을 버는 유즈맵 돈타워 초기버전 (럭이랑)](https://youtu.be/Dm7ztCu3iJY).
영상의 자막(1시간 20분 실황)과 화면 캡처(유닛 정보창, 명령 카드 툴팁, 미니맵, 자원 표시)에서 확인한 내용을 옮겼습니다.

## 화면 구성 (워크3 그대로)

- **상단 바**: 메뉴, 퀘스트(완료 수), 배속, 다음 라운드, 골드 🪙, 목재 🌲, 식량 🍗 (사용량/100), 유지비 표시
- **오른쪽 위 Kills 판**: 난이도·처치 수, 라운드, 필드 몹 수(난이도별 한도), 다음 라운드까지 남은 시간, **다음 라운드 특성 미리보기**
- **하단 콘솔**
  - 미니맵 (보스는 주황, 황금 돼지는 금색)
  - 초상화와 체력
  - 정보창: 데미지 `최소 - 최대 +보너스`, 아머, 식량, 건설·연구·영웅 경험치 진행 바
  - 4×3 명령 카드: 단축키 Q W E R / A S D F / Z X C V, 업그레이드 U, 이동 M
  - 마우스를 올리면 뜨는 툴팁: `(키) 이름 · 비용 · 요구 사항 · 설명`
- **맵**: 눈 덮인 얼음 절벽 길. 좌상단 입구에서 내려와 지그재그로 오른쪽 중앙 원형 광장까지 갑니다.

## 핵심 규칙

- **일용직 노동자**: 타워를 짓는 일꾼입니다. 아머 1000이라 절대 죽지 않습니다. 최대 6명까지 고용합니다.
- **돈타워**: 공격의 일정 데미지를 돈으로 축적하는 타워입니다.
  - 몹은 치지 않고 사거리 안의 **노동자를 때려** 공격력의 10%를 골드로 법니다.
  - 1단부터 5단까지 있습니다. 2단은 152, 3단은 252, 4단은 302 데미지로 원작 수치와 같습니다.
- **타워 놀이방 → 초등학교 → 중학교 → 고등학교 → 대학교**
  - 싼 기본 타워입니다. 놀이방 데미지 17~25는 원작 수치와 같습니다.
  - **돈 벌기**로 바꾸면 노동자를 때려 돈을 법니다. 이때는 몹을 공격하지 않습니다.
- **유지비**: 식량 사용량에 따라 모든 수입이 줄어듭니다. 원작 툴팁 그대로이고, '노조 협상' 연구로 구간이 10씩 늘어납니다.
  - 0~50: 유지비 없음 (100%)
  - 51~80: 낮은 유지비 (70%)
  - 81~100: 높은 유지비 (40%)
- **목재**: 다음 네 가지 방법으로 얻습니다.
  - 5라운드마다 오는 **목재 타임**에 처치할 때마다 +30
  - 보스 처치 +300
  - 부동산
  - 연구소에서 골드 1000을 목재 200으로 구입
- **무한 라운드 (성지키기 방식)**
  - 라운드에 끝이 없습니다.
  - 못 잡은 몹은 사라지지 않고 도착 지점에서 입구로 돌아가 **계속 돌며 쌓입니다**.
  - 소환이 끝나면 15초 뒤 다음 라운드가 옵니다. 필드 몹이 **난이도별 한도**(하수 60 · 중수 50 · 고수 45 · 초고수 40 · 하드코어 30)를 넘으면 정리될 때까지 다음 라운드가 멈춥니다. 보스는 10마리로 셉니다.
  - 게임 오버는 없고, 메뉴의 '게임 끝내기'로 끝냅니다. 기록은 난이도별 최고 도달 라운드입니다.
- **공중 라운드**: 9·17·26·33·39·42라운드, 45라운드 이후로는 8라운드마다(49·57·65…) 옵니다. 길 위를 1.6배 빠르게 날아오고, 대공 가능한 타워만 칠 수 있습니다.
- **라운드 진행**: 첫 라운드까지 30초 준비 시간이 있습니다. Space로 다음 라운드를 바로 부를 수 있습니다(필드 한도 초과 시 불가).

## 몹 특성 · 보스

4라운드부터 12라운드 주기로 특성이 바뀝니다. 오른쪽 위 Kills 판에서 다음 라운드 특성을 미리 볼 수 있습니다.

| 특성 | 효과 | 대응 |
|---|---|---|
| 💨 신속 | 이동속도 ×1.5, 체력 80% | 슬로우 |
| 🛡️ 중장갑 | 방어력 ×3 +10 | 저주 타워 |
| 🐜 무리 | 마릿수 2배, 체력 45% | 멀티샷·체인·대포 |
| 💚 재생 | 초당 최대 체력 2.5% 회복 | 독 (중독 중엔 재생 멈춤) |
| 🧬 분열 | 죽으면 35% 체력 몹 2마리 | 범위 공격 |
| ✨ 마법 면역 | 슬로우·스턴·물·독·저주 무시 | 순수 화력 |
| 👻 은신 | 탐지 범위 안에서만 공격 가능 | CCTV 타워·경비 아저씨 |
| ⛰️ 거대 | 마릿수 40%, 체력 3배 | 처형·고화력 |
| 🔷 보호막 | 최대 체력 40% 보호막 | 화력 |
| 💸 좀도둑 | 한 바퀴 돌 때마다 골드를 훔침 | 놓치지 말 것 |

**보스**는 10라운드마다 나옵니다. 부하 10마리를 데려오고, 아래 6종이 순서대로 돕니다. 잡으면 큰 골드와 목재 300을 줍니다.

| 보스 | 능력 |
|---|---|
| 💼 사채업자 | 맞을 때마다 돈을 떨굽니다. 바로 잡지 말고 피빼기를 하세요 (원작 포에버) |
| 🎩 고리대금업자 | 3초마다 주변 몹과 자신을 회복합니다 |
| 🐲 조폭 두목 | 5초마다 부하 3마리를 부릅니다 (최대 24마리) |
| 🤵 재벌 3세 | 마법 면역이고, 8초마다 보호막을 두릅니다 |
| 🏢 건물주 | 엄청난 체력, 아주 느림 |
| 👑 돈의 신 | 돈 떨구기·회복·소환·보호막을 모두 씁니다 |

**🐷 황금 돼지**는 7·17·27… 라운드에 한 마리 섞여 나옵니다. 잡으면 큰 골드를 주고, 도착 지점에 닿으면 도망칩니다.

## 타워 연구소

메인 메뉴에는 다섯 가지 명령이 있습니다.

- 노동자 고용
- 목재 구입
- **연구 ▶**
- **영웅 소환 ▶**
- **랜덤 영웅 뽑기**

**연구 11종**

- 단계형 8종: 공격력(+10%/5단계), 공격속도(+8%/5), 사거리(+6%/3), 슬로우 강화(+5%p/3), 돈타워 수입(+15%/5), 처치 골드(+20%/3), 노조 협상(유지비 구간 +10/3), 영웅 훈련(경험치 +30%/3)
- 동네 아저씨 연구 체인: **피시방 야간정액 → 여자에 굶주린 상태 → 턱수염**

**영웅 13명** — 처치할수록 레벨이 오릅니다(최대 Lv.30, 레벨마다 공격력 +7%·공속 +2%). 우클릭이나 이동(M)으로 옮깁니다.

| 영웅 | 특징 |
|---|---|
| 👵 옆집 아줌마 | **물 끼얹기** 범위 감속. 2단 데미지 3~361 |
| 👧 옆집 딸내미 | **이너파이어**: 넓은 범위 공격력 +30% |
| 🦺 공익근무요원 | 데미지 3502, 공중에 2배, 주변 공속 +20% |
| 🧔 동네 아저씨 (최대 2) | 턱수염 연구와 흡연구역이 필요합니다. 공갈협박으로 피해의 10%를 돈으로 뜯고, 치명타 30% |
| 🧥 노숙자 (최대 3) | 싸고 경험치 2배 |
| 🛵 치킨 배달부 | 초고속 연사, 2명 동시 공격. 배달 완료: 5초간 공속 2배 |
| 👩‍🏫 학원 선생님 | 숙제 폭탄: 범위 기절 |
| 👮 경비 아저씨 | 은신 탐지 오라. 호루라기: 범위 감속 |

| 🚕 택시 기사 | 총알택시: 앞서가는 적 8명에게 큰 피해 |
| ⚔️ 쌍칼 (히든) | 연속 베기 |

## 퀘스트 22개 (F9)

첫 돈타워, 돈타워 5단, 옵션 타워 11종 보유, 보스 5마리, 히든 영웅 획득, 영웅 Lv.15, 연구 합계 15단계, 40라운드 도달, 로또 1등, 황금 돼지 3마리, 필드 0마리로 라운드 시작 10회 등이 있습니다. 완료하면 골드나 목재를 바로 받습니다.

## 조작

- 좌클릭: 선택. 빈 땅을 클릭하면 건설 메뉴가 열립니다
- 우클릭: 유닛 이동, 건설 취소
- 휴대폰: 우클릭 대신 유닛을 고른 뒤 **이동(M)** 버튼을 누르고 갈 곳을 터치합니다. 상단 바는 두 줄(자원 / 버튼·라운드)로 바뀝니다
- Shift+클릭: 같은 건물을 연속으로 건설
- 단축키: 명령 카드 키, U 업그레이드, T 돈 벌기 전환, V 판매·뒤로, M 이동, Esc 메뉴 닫기·취소
- Space 다음 라운드 · F 배속(1~3x) · F9 퀘스트 · P/F10 일시정지

## 밸런스

수치는 모두 파일 위쪽 표에 모여 있습니다: `CFG`, `DIFFS`, `UPKEEP`, `TRAITS`, `TRAIT_CYCLE`, `BOSSES`, `D`(`makeLine` 표), `OPT_LINES`, `RES`, `ITEMS`, `CONSUMABLES`, `QUESTS`, `PATH`.

몹 체력은 10라운드까지 라운드마다 ×1.3, 그 뒤로는 ×1.12씩 늘어납니다(1라운드 40).

자동 플레이 봇으로 측정한 도달 라운드입니다. 봇은 필드가 10분 넘게 멈추면 진 것으로 쳤습니다.

|---|---|---|
| 하수 | 60 | 영웅 5명, 아이템 3개 |
| 중수 | 44 | 경비 아저씨만 |
| 하드코어 | 30 | 없음 |

이 봇은 돈타워와 영웅에 투자를 잘 못하므로, 사람이 하면 더 멀리 갈 수 있습니다.
